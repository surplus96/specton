# ADR-0002: MVP 범위

- 날짜: 2026-10-23
- 상태: 제안
- 결정자: 팀 설계로 (회의에서 승인·수정·보류)

## 배경

기간은 평일 10일이다. 요구사항 27개 중 REQ-19(웹), REQ-25(자원 한도), REQ-27(HWPX·HWP)이 축소 후보다.

## 결정

- REQ-27 HWPX·HWP: MVP 제외, HWPX 텍스트 추출은 stretch(여유가 생기면 착수).
- REQ-18 내보내기(확정): 중간 산출물은 Markdown. PDF는 승인된 최종 기능 명세서·ERD만 승인 시점에 1회 생성. DDL은 SQL, RTM은 Excel·CSV.
- REQ-19 웹: 업로드 → 확인·승인 → 결과 보기, 화면 3개.
- REQ-25 한도: 실행 타임아웃만 둔다. 취소 기능 포함 여부는 회의에서 정한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| 기획한 전체 범위 유지 | 요구사항 전부 충족 | 기간 내 완료 불가 | 일정 |
| 단계마다 PDF 생성 | 중간 결과 공유 편함 | 구현 범위 증가 | Markdown으로 충분 |

## 결과

- 좋아지는 점: 구현 범위가 기간에 맞는다.
- 감수할 점: 줄인 범위를 [02 요구사항](../02-requirements.md) 표에 바로 반영해야 미충족 항목으로 남지 않는다.
