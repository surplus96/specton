# ADR-0007: LLM 사용 조건

- 날짜: 2026-10-23
- 상태: 제안
- 결정자: 팀 설계로 (회의에서 승인·수정·보류)

## 배경

고객 문서를 외부 LLM API로 보내도 되는지 확인되지 않았다. 실행 1회의 최악 호출 수는 (설계 4 + 검토 4 + 라우터 1) × (최초 1 + 재작업 3) = 약 36회다. 병렬 검토는 호출 한도(429)에 걸릴 수 있다.

## 결정

- 외부 LLM 사용이 확인되기 전까지 합성·비식별 데이터만 쓴다.
- 모델은 2단계: 설계(A01~A04) 상위 모델, 검토·라우터(A05~A09) 저가 모델.
- 예산 상한을 숫자로 정하고, 동시 호출 수 제한과 재시도 백오프를 둔다.
- 실제 LLM 호출 테스트(`-m llm`)는 예산 승인 후 수동 실행한다.

| 회의에서 정할 값 | 값 |
|---|---|
| 팀 전체 예산 상한 | $ |
| 하루 예산 상한 | $ |
| 설계 역할 모델 | |
| 검토·라우터 모델 | |
| 실행 타임아웃 | 분 |

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| 승인 후 실데이터 사용 | 실제 품질 확인 | 승인 전까지 개발 정지 | 일정 |

## 결과

- 좋아지는 점: 보안 확인을 기다리지 않고 개발할 수 있다.
- 감수할 점: 합성 데이터 결과가 실제 문서 성능을 보장하지 않는다.
