# ADR-0007: LLM 사용 조건

- 날짜: 2026-10-26
- 상태: 승인
- 결정자: 팀 설계로 전원 (팀 회의)

## 배경

에이전트 9개(A01~A09)가 OpenAI API를 호출한다. 고객 문서를 외부 LLM으로 보내도 되는지는 아직 확인되지 않았다. 실행 1회의 최악 호출 수는 (설계 4 + 검토 4 + 라우터 1) × (최초 1 + 재작업 3) = 약 36회다. 병렬 검토는 호출 한도(429)에 걸릴 수 있다. 기존 설정 기본값(`gpt-4o`, `gpt-4o-mini`)은 현재 세대보다 두 세대 앞선 모델이다.

## 결정

**데이터**

- 외부 LLM 사용이 확인되기 전까지 합성·비식별 데이터만 보낸다.

**모델**

| 역할 | 모델 | 추론 강도 | 가격 (입력 / 출력, 100만 토큰당) |
|---|---|---|---|
| 설계 A01~A04 | `gpt-6.1-sol` | medium | $2 / $10 |
| 검토·라우터 A05~A09 | `gpt-6-luna` | low | $0.10 / $0.50 |
| 대체 경로 (설계 / 검토) | `gpt-5.6-terra` / `gpt-5.6-luna` | medium / low | $2 / $12, $0.20 / $1.20 |

- 대체 경로는 설정값(`SPECTON_DESIGN_MODEL`, `SPECTON_REVIEW_MODEL`)만 바꿔 전환한다. 코드는 바꾸지 않는다.
- 평가 기간에는 모델을 바꾸지 않는다. 호출마다 모델 ID를 기록한다.
- 가격은 2026-10-26 OpenAI 공식 가격표 기준이다.

**예산과 한도**

| 항목 | 값 | 적용 위치 |
|---|---|---|
| 팀 전체 예산 상한 | $150 | OpenAI 프로젝트 예산 한도·알림 |
| 하루 예산 상한 | $25 | OpenAI 사용량 알림 + 팀 공유 |
| 실행 1회 토큰 한도 | 400,000 | `SPECTON_MAX_TOKENS_PER_RUN` |
| 실행 1회 시간 한도 | 15분 | `SPECTON_RUN_TIMEOUT_SECONDS` |
| 호출 1회 타임아웃 | 120초 | `SPECTON_LLM_TIMEOUT_SECONDS` |
| 호출 1회 출력 토큰 한도 | 8,000 | `SPECTON_MAX_OUTPUT_TOKENS` |
| 구조화 출력 재요청 | 최대 2회 | `SPECTON_MAX_STRUCTURED_RETRIES` |
| 동시 호출 수 | 4 | `SPECTON_LLM_CONCURRENCY` |
| 429·일시 오류 재시도 | 최대 3회, 지수 백오프 | `SPECTON_LLM_API_RETRIES` (OpenAI SDK 내장 재시도 사용) |

**운영**

- OpenAI 콘솔에 Specton 전용 프로젝트를 두고, 결제·프로젝트 관리는 R1(최태영)이 맡는다.
- API 키는 팀원별로 발급한다. 키는 각자 `.env`에만 두고 저장소·로그·CI에 넣지 않는다.
- 단위 테스트는 stub client를 쓴다. 실제 호출 테스트(`-m llm`)는 통합 확인과 평가에만 수동으로 실행한다.
- 공통 LLM client 구현(#3) 후 대표 문서로 실제 호출 5회를 시범 실행해 토큰을 재고, 예산을 다시 확인한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| 설계에 `gpt-6-astra` | 최고 품질 | 비용 5배 ($10 / $50) | 예산 안에서 평가 반복이 어려움. 시범 실행에서 품질이 부족하면 A03·A04에 한해 재검토 |
| 5.6 세대 (`gpt-5.6-sol` + `gpt-5.6-luna`) | 출시 후 기간이 더 김 | 비용 약 2배, 학습 기준일 더 오래됨, Sol은 프로모션가 | 비용·최신성에서 불리. 대체 경로로만 유지 |
| 기존 기본값 (`gpt-4o` + `gpt-4o-mini`) | 설정 변경 없음 | 두 세대 이전 모델 | 품질·가격 모두 불리 |
| 승인 후 실제 고객 문서 사용 | 실제 품질 확인 | 승인 전까지 개발 정지 | 일정 |

## 결과

- 좋아지는 점: 실행 1회 비용이 정상 약 $0.2, 최악 약 $2.5로 예측 가능하다. 한도 설정으로 비용 폭주를 막는다. 모델 교체가 설정값만으로 된다.
- 감수할 점: `gpt-6.1-sol`은 출시 약 4주 된 모델이라 동작 변화 위험이 있다. 합성 데이터 결과가 실제 문서 성능을 보장하지 않는다. 비용 추정은 가정에 기반하므로 시범 실행으로 확인해야 한다.
