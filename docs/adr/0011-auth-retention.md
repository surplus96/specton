# ADR-0011: 인증·보존

- 날짜: 2026-10-23
- 상태: 제안
- 결정자: 팀 설계로 (회의에서 승인·수정·보류)

## 배경

시연용 서비스이며 공개 운영을 전제하지 않는다. 업로드 문서에는 민감 정보가 있을 수 있다.

## 결정

- 로컬 단일 세션, 모든 run 접근은 서버의 `owner_ref`로 검사한다.
- 업로드 파일과 산출물은 시연 후 삭제한다. 삭제는 DB·파일·체크포인트를 함께 처리한다.
- AWS 배포 시 접근은 IP 제한으로 막는다 (ADR-0013).

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| 외부 인증(OAuth 등) | 실서비스에 가까움 | 구성·테스트 부담 | 기간 대비 과함 |

## 결과

- 좋아지는 점: 구현이 단순하다.
- 감수할 점: 다중 사용자 서비스로 확장하려면 인증을 새로 설계해야 한다.
