# ADR-0014: 평가 목표·데이터

- 날짜: 2026-10-23
- 상태: 제안
- 결정자: 팀 설계로 (회의에서 승인·수정·보류)

## 배경

성능을 보여 줄 평가 데이터와 정답, 목표값이 정해지지 않았다. 팩 작성자가 평가 문서를 보면 결과가 부풀려진다.

## 결정

- 초기 평가 세트: 재고 5건, 설비 3건.
- 개발용 세트(팩 보완·few-shot)와 평가용 세트(팩 작성자 미열람)를 분리한다. 평가 세트·정답 작성자는 팩 작성자와 다른 사람이다.
- 평가 세트 수집과 정답 작성은 R3 박성진이 맡는다 (2026-10-25 확정). 팩 작성자(R2)는 팩을 `approved`로 고정한 뒤에만 평가 문서를 본다.
- 평가 전 팩을 `status: approved`로 고정한다.
- 데이터와 정답은 공개 저장소에 올리지 않고 팀 비공개 위치에 둔다.
- 목표값은 첫 기준 실행 후 정한다.

| 회의에서 정할 값 | 값 |
|---|---|
| 평가 세트·정답 작성 담당 | R3 박성진 (@c189021) — 확정 |
| 데이터 저장 위치 | |
| 지표 목표값 | 기준 실행 후 |

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| 팩 작성자가 평가 세트도 작성 | 인력 절약 | 정답 누출·과대 성능 | 공정성 |

## 결과

- 좋아지는 점: 평가 결과를 근거로 쓸 수 있다.
- 감수할 점: 정답 제작에 별도 인력이 필요하다.
