# ADR-0012: 실행기 구조

- 날짜: 2026-10-23
- 상태: 제안
- 결정자: 팀 설계로 (회의에서 승인·수정·보류)

## 배경

설계 실행은 길고 HITL에서 멈췄다가 재개된다. API 요청 스레드에서 동기로 실행하면 안 된다.

## 결정

- API 프로세스 안의 백그라운드 작업으로 실행하고, LangGraph Postgres 체크포인터로 상태를 저장한다.
- 영속 run 레코드와 작업 lease로 run당 실행자를 1개로 제한한다. 프로세스가 죽으면 lease 만료 후 마지막 체크포인트에서 재개한다.
- 외부 메시지 큐는 두지 않는다.

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 이유 |
|---|---|---|---|
| Celery 등 외부 큐 | 확장성 | 구성·운영 부담 | 시연 규모에 과함 |
| 요청 안에서 동기 실행 | 단순 | 타임아웃·재개 불가 | 요구사항 위반 |

## 결과

- 좋아지는 점: 구성이 단순하고 재개가 된다.
- 감수할 점: API 프로세스를 재시작하면 진행 중 작업이 lease 만료까지 멈춘다.
