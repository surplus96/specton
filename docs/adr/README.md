## 작성 규칙

- 새 결정은 [template.md](template.md)를 복사해 `NNNN-영문-슬러그.md`로 만든다.
- 승인되면 상태를 "승인"으로 바꾸고, 개발 문서의 `제안 (ADR-NNNN)` 표시를 확정 내용으로 고친다.
- 바뀐 결정은 새 번호로 기록하고 이전 ADR에 "대체됨: ADR-NNNN"을 적는다.
- 회의에서 숫자로 정할 값(예산, 모델, 담당 등)은 해당 ADR의 빈칸에 적는다.
